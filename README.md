# Python Foundations Labs

An introductory Python coursework worksheet covering lists and strings.

## Included material

`lab1.py` contains commented prompts for indexing, slicing, list updates, membership checks and basic string operations.

**Status: worksheet only.** The supplied file contains no implemented solutions or trained model. AI-themed sample text does not make this an AI project. It is kept here as learning material and is not presented as a completed application.
