# Python Foundations Labs

Introductory learning exercises in Python lists and strings. These are small worked examples, not a machine-learning model.

## Run

Install Python 3 and run:

```sh
python lab1.py
```

No third-party packages are required.

## Topics

- Indexing, negative indexing and slicing
- Updating and appending list items
- Length, minimum, maximum and membership checks
- Trimming, lowercasing, replacing and splitting strings

## Learning notes

The original coursework file contained exercise prompts. Executable worked solutions were added during the portfolio review with AI assistance. Each operation is printed with a label so its result can be compared with the source.
